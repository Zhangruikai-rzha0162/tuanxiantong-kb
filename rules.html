分工总览

以下规则整理自测试计划中的四个规则 sheet，与需求规格说明书 4.2 节对应。每条规则标注了校验方：核心 / 团险通 / 双系统均校验 / 均不校验。可用每组表格上方的筛选器按校验方过滤。

记法：双系统校验 = 两端都执行（基础字段）；仅核心 = 需险种规则 / 数据库访问的复杂判断；仅团险通 = 简化范围、在途状态等即时反馈规则。带"团险通校验 = 是"的规则在核心侧受开关控制（见校验开关设计）。

通用客户信息规则

适用于 NI / IR 清单中的客户信息校验，基础字段不分长短险均为必录。

#字段 / 校验点规则摘要提示语核心团险通
1姓名只能含字母或汉字、"·"、空格；字母与汉字二选一；汉字 / 非汉字有最少长度限制【姓名】格式错误是是
2性别非空，仅"男 / 女"【性别】格式错误是是
3出生日期非空，日期格式（2022/01/01 或 2022-01-01）【出生日期】格式错误是是
4证件类型限身份证、户口簿（16 周岁以下）、出生医学证明（3 周岁以下）等法定类型【证件类型】格式错误是是
5证件号码按证件类型校验合法性（身份证 18 位、校验位等）【证件号码】格式错误是是
6性别 × 证件号码身份证 / 户口簿：倒数第 2 位奇男偶女【性别】与【证件号码】不符是是
7出生日期 × 证件号码身份证 / 户口簿 / 港澳台居住证：出生日期与号码对应位一致【出生日期】与【证件号码】不符是是
8国籍 × 证件类型身份证 / 户口簿 → 国籍中国；通行证 / 居住证 → 对应地区【国籍】与【证件类型】不符是是
9证件有效期起止期模板含该字段才校验：非空 + 日期格式（含基本信息模板必录）【证件有效期起期】或【止期】格式错误是否
10国籍非空【国籍】格式错误是是
11职业代码非空且须为公司职业代码表中的码值（必录）【职业代码】格式错误是是
12联系电话模板含该字段则非空并校验格式（不含基本信息模板无此字段）【联系电话】格式错误是否
13联系地址含基本信息模板必录；模板无此字段则不校验【联系地址】格式错误是否
14是否有医疗保障非空，仅"是 / 否"【是否有医疗保障】格式错误是是

新增被保险人（NI）

#校验点规则摘要提示语核心团险通
1与投保人关系模板含该字段则非空（含基本信息模板必录）【与投保人关系】格式错误是否
2保险方案代码非空，且为合同下已有方案之一【保险方案代码】格式错误是是
3责任起期 · 格式日期格式；团险通不做非空校验（空则自动赋值）【保险责任起期】格式错误是是
4责任起期 · 精确范围不早于合同起期；新增附属被保人不早于其主被保人责任起期【保险责任起期】不得早于 / 晚于某日是否
5责任起期 · 简化范围≥ 合同起期且 ≥ 提交次日；未填则默认提交日次日【保险责任起期】不得小于 / 大于某日否是
6主被保人姓名与主被保人关系不为"本人"时必填【主被保险人姓名】不能为空是是
7主被保人证件号码同上，不为"本人"时必填【主被保险人证件号码】不能为空是是
8主被保人存在性姓名 + 证件号在承保中（有效 / 满期 / 投保中）或本清单内可查未查询到主被保险人信息是否
9与主被保人关系主被保人姓名 + 证件号有值时必填【与主被保险人关系】不能为空是是
10月薪方案为月薪方案时必录；仅允许数值【月薪】格式错误是是
11基本保险金额 / 保险费长险必录，仅数字【基本保险金额/保险费】格式错误否否
12个人税收居民身份长险必录，限三类枚举值【个人税收居民身份】格式错误否否
13重复新增已在承保中（有效 / 满期 / 投保中）或清单内重复被保险人已在承保中，无需新增是否
14长险模板适用性按方案险种判断清单模板是否使用正确（长险规则）增加被保险人清单使用错误否否
15险种层 · 医疗保障社保补充类医疗险种：【是否有医疗保障】必须为"是"被保险人无医疗保险，不允许新增是否
16险种层 · 性别限制女性特疾 / 生育类险种不能为男性被保险人性别不符合险种要求是否
17在途冲突不能同时在本保单其他在途保全的申请名单中被保险人正在办理其他保全业务否是

替换被保险人（IR）

#校验点规则摘要提示语核心团险通
1替出被保人姓名非空【替出被保险人姓名】格式错误是是
2替出被保人证件号码非空【替出被保险人证件号码】格式错误是是
3替出人存在性姓名 + 证件号须命中有效 / 满期被保人；清单内不重复替出（含已理赔终止的合并判断）未查询到替出被保险人信息是否
4替出人理赔中正在理赔中的被保人不允许替换被保险人**正在理赔中，不允许替换是否
5替出人已理赔有已结案且赔付 > 0 记录的不允许替换被保险人**已发生理赔，不允许替换是否
6替出人有附属被保人存在附属被保险人的不允许替换存在附属被保险人，不允许替换是否
7与投保人关系模板含该字段则非空（含基本信息模板必录）【与投保人关系】格式错误是否
8责任起期 · 格式日期格式【保险责任起期】格式错误是是
9责任起期 · 精确范围不早于替出被保人个单生效日（预约增人则不早于其责任起期）；不晚于替出被保人责任止期【保险责任起期】不得早于 / 晚于某日是否
10责任起期 · 简化范围同增人：≥ 合同起期且 ≥ 提交次日【保险责任起期】不得早于 / 晚于某日否是
11方案适用性费率型保费（折扣 / 约定 / 期望费率）或月薪倍数 / 非固定保额方案不允许替换对应保险方案不允许替换被保险人是否
12替入人重复姓名 + 证件号已承保（有效 / 满期 / 投保中）或清单内重复替入被保险人**已在承保中，无需替入是否
13险种层 · 医疗保障社保补充类医疗险种要求有医疗保障被保险人**无医疗保障，不允许替换是否
14险种层 · 性别限制女性特疾 / 生育类险种不能为男性被保险人**性别不符合险种要求是否
15在途冲突同增人：不能在其他在途保全名单中被保险人正在办理其他保全业务否是

减少被保险人（ZT）

减人清单的关键字段是保险责任止期；线上"是否全额退费"默认处理为"否"。

#校验点规则摘要提示语核心团险通
1姓名非空【姓名】格式错误是是
2证件号码非空【证件号码】格式错误是是
3责任止期 · 格式日期格式【保险责任止期】格式错误是是
4责任止期 · 精确范围未理赔：不早于个单生效日（预约增人不早于其责任起期）；已理赔：不早于最大事故日期【保险责任止期】不得早于 / 晚于某日是否
5责任止期 · 简化范围上传当日 ≤ 责任止期 ≤ 合同终止日【保险责任止期】不得早于 / 晚于某日否是
6被保人存在性姓名 + 证件号须命中有效 / 满期被保人；清单内不重复减人（含已理赔终止的合并判断）未查询到被保险人信息是否
7理赔中正在理赔中的被保人不允许减少被保险人正在理赔中，不允许减少是否
8已理赔终止个单下险种全部非满期终止的（已合并至"未查询到被保险人信息"）名下保单已理赔终止，不允许减少是否
9存在附属被保人须先减少附属被保险人存在附属被保险人，请先减少附属被保险人是否
10是否全额退费仅"是 / 否"；线下校验项，线上默认"否"【是否全额退费】格式错误是否
11虚拟被保人规则已删除（虚拟被保险人不允许变更）—否否
12在途冲突不能在其他在途保全名单中被保险人正在办理其他保全业务否是

清单模板说明

  • NI 增人：不再使用原通用模板，新增"新增被保险人清单-短期险"与"新增被保险人清单-短期险（含基本信息）"两个模板；保单下存在长险时页面保持原模板。
  • IR 换人：新增"更换被保险人模板"与"更换被保险人模板（含基本信息）"；短险模板删除"与主被保人关系 / 主被保人姓名 / 证件号码"三字段——替出人若为附属被保人，系统自动处理：替入人默认附属、主被保人及关系均继承替出人。
  • ZT 减人：关键字段为"保险责任止期"。
